# LocalSDR
Autor: Roger Cruz Roura

Context:Fer la instal·lació d’una antena SDR (software defined radio) a l’institut per captar i analitzar senyals de ràdio a través de un programa per Internet i permet escoltar diferents freqüències.

Abast: L’abast del projecte inclou la definició del material i els recursos necessaris per poder realitzar la instal·lació teòrica d’un sistema SDR. Per dur-lo a terme caldria un ordinador amb connexió a Internet, un dispositiu SDR (com un RTL-SDR USB), una antena adequada per a la recepció, un cable coaxial per fer la connexió i un suport per col·locar l’antena. També seria necessari utilitzar un programari de recepció de senyals com SDRSharp, CubicSDR o un receptor web tipus OpenWebRX
